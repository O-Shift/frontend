# OShift Frontend

Vocabulary for the OShift web app's design system and application shell.

## Language

### Shell

**App shell**:
The persistent chrome — collapsible sidebar plus content region — that wraps every authenticated page.
_Avoid_: layout, frame

### Design system

**Surface**:
A container background that sits above the page background; one shared token serves all raised containers (dropdowns, command bar, popovers, panels).
_Avoid_: dropdown-bg, sugg-btn-bg, br-pill-bg, v0-sidebar-bg, command-bar-bg

**Landing style**:
The `/landing` marketing identity (pill buttons, serif display accents, pinned dark mode) that deliberately diverges from app-wide primitives.
_Avoid_: lp-btn dialect, marketing theme
